## English

- Open **Life Dashboard** from Calendar to track the things you want to keep up. See your current streak, check-in count, and total time logged. Choose which modules to show: the table, chart, or totals.
- Use **Check in** to log what you did on a date, with an optional duration. Multiple check-ins on one date count as one day toward your streak. Add an item with the same name to bring in existing date-only notes.
- Track things you're avoiding, too. Enter when they last happened; with only a date, the dashboard shows an estimated number of days.

Quit Force before replacing the app. Existing records are kept when the local database is upgraded. Older Force versions cannot open the upgraded database.

## 中文

- 从「日历 → 生活看板」查看想坚持的事项：连续了几天、打卡几次、累计做了多久。事项表、趋势和累计模块可按需显示。
- 「打卡」只需要日期，时长可以选填。同一天可以打卡多次，连续天数只算一天。添加同名事项可计入已有的按日记录。
- 也可以追踪想戒掉的事。填写上次发生的时间；只知道日期时，看板会显示大约坚持了几天。

更新前请退出 Force，再替换应用。升级本地数据库时会保留已有记录，旧版 Force 无法打开升级后的数据库。
