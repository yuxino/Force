## English

- Tasks, notes and arrangements now use consistent centered dialogs. Arrangements default to today, and unfinished arrangements keep their activity editable after saving.
- New tasks default to count-up timing, with activity selection first and an optional description.
- Add timestamped notes, backfill past work, and correct records or task completion times from the calendar.
- Review focus trends, daily totals and the activity calendar, with consistent classification colors.
- The docked clock uses a small paw when idle and a compact time tab while timing. Click for the full clock and timer controls.

Quit Force before replacing the app. Existing tasks and records are retained. First launch upgrades the local data format; v0.1.2 and earlier cannot read the upgraded data.

Choose `aarch64` for Apple silicon or `x86_64` for Intel Mac. macOS 15+ is required; GitHub Mac packages are not notarized. Windows requires the [Visual C++ v14 x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Linux packages are built on Ubuntu 24.04 and require system graphics/audio libraries.

Native checks covered Apple silicon macOS. Intel Mac and Windows/Linux desktop interaction, IME composition and long-distance dragging still need verification.

更新前退出 Force，再替换应用，原有任务和记录会保留。首次启动会升级本地数据格式，升级后 v0.1.2 及更早版本无法读取。

已在 Apple 芯片 macOS 上进行原生检查。Intel Mac、Windows/Linux 桌面交互、输入法组合输入和长距离拖动仍待验证。
