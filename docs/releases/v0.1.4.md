## English

- New-task, note and arrangement dialogs now fit their content, with scrolling when needed.
- New tasks highlight “Start timing”, with “Save task” as a secondary action.

Quit Force before replacing the app. Existing tasks and records are retained. Upgrading from v0.1.2 or earlier updates the local data format; those versions cannot read it afterward.

Choose `aarch64` for Apple silicon or `x86_64` for Intel Mac. macOS 15+ is required; GitHub Mac packages are not notarized. Windows requires the [Visual C++ v14 x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Linux packages are built on Ubuntu 24.04 and require system graphics/audio libraries.

Native interaction checks covered standard windows on Apple silicon macOS only.

## 中文

- 新任务、随手记和安排弹窗按内容收紧，内容较多时可滚动。
- 新任务突出“开始计时”，“保存任务”作为次要操作。

更新前退出 Force，再替换应用，原有任务和记录会保留。从 v0.1.2 或更早版本升级会更新本地数据格式，之后这些旧版本无法读取。

Apple 芯片 Mac 选择 `aarch64`，Intel Mac 选择 `x86_64`。Mac 需要 macOS 15 或更新版本，GitHub Mac 安装包未公证。Windows 需要 [Visual C++ v14 x64 运行库](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)。Linux 安装包基于 Ubuntu 24.04 构建，需要系统图形与音频库。

仅在 Apple 芯片 macOS 的常规窗口完成原生交互检查。
