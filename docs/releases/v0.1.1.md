下载适合你系统的文件：Mac 的 `aarch64` 对应 Apple 芯片，`x86_64` 对应 Intel；Windows 和 Linux 提供 x86_64 版本。

macOS 需要 15 或更新版本。打开 DMG 后将 Force 拖入“应用程序”。此 GitHub 安装包未经过 Apple 公证，首次打开若被系统拦截，可在系统设置“隐私与安全性”中确认“仍要打开”。Windows 解压后运行 Force.exe；Linux 解压后运行 Force/force（基于 Ubuntu 24.04 构建，需要系统图形与音频库）。

更新时先退出 Force，再用新版替换应用。任务和计时记录保存在应用之外，更新会保留记录。
