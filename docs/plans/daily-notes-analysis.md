# 随手记、时间选择与分析

## 时刻

“随手记”保存内容和一个本地日期/时间，不需要结束时间，不创建任务或区间。入口在主导航和当天记录中；月历、当天列表、时间轴与记录搜索都能找到它。多行输入用普通回车换行，Cmd/Ctrl+Enter 保存；关闭或切换页面保留草稿，取消才丢弃。

时刻使用独立 SQLite 表，删除为软删除。版本 7 增加时刻，版本 8 增加分类颜色；升级事务失败时保留旧数据库。计时 CSV 仍只导出计时记录。

## 时间拨盘与猫钟

安排起止时间和随记时刻共用小时/分钟拨盘，保留精确键盘输入。拨盘编辑临时值，确认才写回；取消、Escape 和关闭不修改原值。刻度声默认关闭，只在主动调整到新刻度时短促播放；macOS 和 Windows 支持，其他平台不显示该选项。猫钟普通分秒读数缩小，长时长读数仍按位数收缩。

## 分类

设置中统一管理正向、中性、负向和休闲的颜色。标签未指定颜色时跟随分类，也可以覆盖；已有自定义颜色保留。所有页面使用相同的颜色解析顺序。分类颜色是显示设置，不重写历史记录的分类快照或统计口径。

## 分析

最近 7、30、90 天的真实专注趋势与逐日表格。专注时间合并重叠区间，分类投入分别累计，并在表格说明重叠含义。没有记录的日期显示零，不生成示例数据。数据读取按时间段批量查询，计时中仅更新今天；随记不贡献时长。

## 活动与历史记录

新任务默认正计时，不自动选择活动。选活动即可开始或保存；说明选填，相同名称不重复显示，已有独立说明保留。倒计时才显示分钟设置，切换方式保留尚未使用的时长草稿。

记录页支持补记和编辑已结束的记录。补记可选过去的起止日期和时间，结束时间即新任务的完成时间；不会改变正在运行的计时。编辑保留每段计时及暂停间隔，未修改的时间保留原秒数和具体时刻。原活动已归档时仍可保持原活动并编辑时间或说明。真正修改时间后，相关任务的完成时间按关联关系同步；独立设置的完成时间保持独立。冲突或并发修改时保留草稿与原记录。

既有数据的分类整理是用户明确授权的一次本地操作：一致性备份后，仅补未分类项并统一颜色，核对原始时间、时长、记录和归档状态不变。分类改变会按现有统计规则重新计算专注时间。此操作不作为自动升级行为应用于其他用户。

## 验证边界

覆盖事务升级、回滚、并发打开，跨日/重叠统计，草稿与原生确认框，键盘保存及焦点闭环，默认/最小窗口布局。TestPlatform 不证明原生像素、真实输入法或声音体验；签名开发应用使用独立测试数据进行原生验收，再安装正式应用并核对签名、文件与启动。
