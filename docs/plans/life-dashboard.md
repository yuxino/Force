# 日历打卡与坚持分析

月历把打卡作为日期内的记录展示，和安排、计时记录共用日期格。点日期可查看当天的打卡和时长；「打卡」用所选日期开始记录，可以选择已有事项或添加新的打卡事项。

「分析 → 坚持」可选择事项及显示内容：累计统计、趋势图和按日明细。打卡趋势可看次数或填写过的时长。每项统计只针对所选事项，显示模块和事项选择保存在本机。

- **坚持做**：先添加事项，再按日期打卡，时长可选填。分析显示当前连续天数、累计打卡天数、次数和已填写的时长。连续天数按本地日期计算，今天还没打卡时保留截至昨天的连续天数；整天漏掉才中断。同一天多次打卡记多次，只占一个打卡日。
- **坚持不做**：按上次发生的时间计算当前坚持天数；只有日期时显示约数。发生一次后重新起算，保留此前的间隔。累计只计每段能确认满 24 小时的天数。已有的戒除事项继续使用这套规则。

添加打卡事项时，未归属其他事项的同名按日记录会计入历史；之后同名的「新建 → 随手记 → 只记日期」也会计入。打卡可以在「记录 → 按日记录」按日期查看、编辑和删除。改名保留关联，移除打卡事项保留原有按日记录。日期和可选时长独立于计时与专注统计。

## 实现与验证

- SQLite v11 增加打卡事项和按日记录的关联，不修改历史记录。测试迁移、同日多次打卡、漏一天、累计时长和删除事项后保留记录。
- 原生界面复用编辑器，验证日期格里的打卡、所选日期的补记、分析选项、原有戒除流程及最小窗口。执行仓库检查与 GPUI 回归，用独立数据打开签名 macOS 预览。
