## 下载与更新

从 [GitHub Releases](https://github.com/yuxino/Force/releases/latest) 下载。Apple 芯片 Mac 选择 `macos-aarch64.dmg`，Intel Mac 选择 `macos-x86_64.dmg`；Mac 需要 macOS 15 或更新版本。Windows 和 Linux 下载对应的 x86_64 压缩包。

Mac 打开 DMG 后将 Force 拖入“应用程序”。GitHub 安装包未经过 Apple 公证；首次打开若被系统拦截，可在系统设置“隐私与安全性”中选择“仍要打开”。Windows 解压后运行 `Force.exe`。Linux 版本基于 Ubuntu 24.04 构建，解压后运行 `Force/force`，需要图形与音频系统库。

在设置页或应用菜单中点击“检查更新”，有新版时可直接下载对应安装包。更新前退出 Force，再替换应用，任务与计时记录会保留。
