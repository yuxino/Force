<details>
<summary>从源码运行</summary>

安装 Rust 和对应平台的开发工具后，在仓库目录运行：

```sh
cargo run --bin force --locked
```

Force 使用 Rust 与 GPUI 构建，支持 macOS、Windows 和 Linux。Windows 与 Linux 的原生交互验证仍在进行中。
