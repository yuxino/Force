Force 是一款带悬浮猫钟的桌面日历与计时工具。无需账号，数据保存在本机。

[下载最新版](https://github.com/yuxino/Force/releases/latest) · [更新说明](https://github.com/yuxino/Force/releases) · [反馈问题](https://github.com/yuxino/Force/issues) · [MIT](LICENSE)

## 功能

- **猫钟**：正计时、倒计时、暂停与继续；macOS / Windows 支持贴边收纳。
- **日历**：安排任务，回看实际计时、完成事项和随手记。
- **记录**：按日查找、补记与修正计时，导出 CSV。
- **分析**：查看专注趋势与活动投入。

## 安装

- **macOS 15+**：Apple 芯片选 `aarch64`，Intel 选 `x86_64`；打开 DMG 后拖入应用程序文件夹。安装包未公证。
- **Windows x64**：解压 ZIP，运行 `Force.exe`；需要 [Visual C++ v14 x64 运行库](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist)。
- **Linux x64**：解压后运行 `force`；基于 Ubuntu 24.04 构建，需要系统图形与音频库。

更新前退出 Force。从 v0.1.2 或更早版本升级前请备份数据，升级后这些旧版本无法读取。
